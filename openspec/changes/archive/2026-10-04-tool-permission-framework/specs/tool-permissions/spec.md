## Purpose

定义工具执行的统一权限把关：判定结果模型、工具以声明式规格参与的方式、进程级策略规则、Run 作用域的判定通道，以及权限判定的轨迹记录，使所有现在与将来的工具共享同一套权限控制。

## ADDED Requirements

### Requirement: 工具执行统一权限把关

每一次工具执行 MUST 经过统一权限判定。在对话执行（Run）作用域内配置了权限判定时，工具 MUST 仅在判定为允许后才真正执行；未配置权限判定时，执行行为 MUST 与无此能力时一致。

#### Scenario: 判定为允许后执行

- **WHEN** 某次工具调用经统一判定结果为允许
- **THEN** 工具处理器被调用并返回正常结果

#### Scenario: 未配置判定时行为不变

- **WHEN** 对话执行未配置权限判定
- **THEN** 工具照常执行，不产生权限事件

### Requirement: 权限判定结果三态

权限判定结果 MUST 为允许、拒绝、询问三者之一。结果为拒绝时工具 MUST NOT 执行；结果为询问且当前无交互审批通道时，MUST 按拒绝处理（fail-closed）。

#### Scenario: 拒绝阻止执行

- **WHEN** 某次工具调用经判定结果为拒绝
- **THEN** 工具处理器不被调用

#### Scenario: 无审批通道的询问按拒绝处理

- **WHEN** 判定结果为询问且当前未提供交互审批通道
- **THEN** 该次调用按拒绝处理，工具不执行

### Requirement: 工具以声明式规格参与权限体系

工具 MAY 声明自身的权限规格，包含默认姿态、面向人的动作描述与用于规则匹配的资源标识；未声明规格的工具 MUST 按全局默认姿态处理。权限框架本身 MUST NOT 针对具体工具硬编码判定逻辑。

#### Scenario: 声明的默认姿态生效

- **WHEN** 某工具声明默认姿态为拒绝
- **THEN** 在没有更具体规则命中时，该工具的调用被拒绝

#### Scenario: 未声明规格的工具按全局默认处理

- **WHEN** 某工具未声明权限规格且全局默认为允许
- **THEN** 其调用被允许

#### Scenario: 资源标识供规则匹配

- **WHEN** 某工具声明了资源标识
- **THEN** 策略规则以这些资源标识匹配该次调用

### Requirement: 进程级权限策略与判定优先级

权限判定 MUST 依据进程级策略求值，策略由全局默认姿态、每工具默认姿态与资源模式规则构成。判定 MUST 按「资源规则 → 工具默认 → 全局默认」求值，取首个命中；资源规则内部拒绝 MUST 优先于允许。全局默认姿态 MUST 可通过环境变量设定。

#### Scenario: 资源规则优先于工具默认

- **WHEN** 某工具默认姿态为询问，但其本次调用的资源命中一条允许规则
- **THEN** 判定结果为允许

#### Scenario: 资源规则中拒绝优先

- **WHEN** 某次调用的资源同时命中一条允许规则与一条拒绝规则
- **THEN** 判定结果为拒绝

#### Scenario: 全局默认可由环境变量设定

- **WHEN** 通过环境变量设定全局默认姿态为拒绝
- **THEN** 未声明规格且无规则命中的工具调用被拒绝

### Requirement: 权限判定随 Run 作用域传递

权限判定 MUST 绑定到发起工具调用的 Run，并随工具执行链传递；判定与授权状态 MUST NOT 在 Run 之间泄漏。

#### Scenario: 并发 Run 互不影响

- **WHEN** 两个 Run 并发执行且各自具有不同权限策略
- **THEN** 每个 Run 的工具调用按各自策略判定，互不干扰

### Requirement: 拒绝以工具错误结果回填

权限拒绝 MUST 以错误工具结果的形式回填给模型，而不是以协议级错误终止请求；Run MUST NOT 因权限拒绝而终止。

#### Scenario: 被拒后 Run 继续

- **WHEN** 某次工具调用被拒绝
- **THEN** 该 Run 收到标记为错误的工具结果并继续后续推理

### Requirement: 权限判定记入执行轨迹

每次权限判定 MUST 记录为所属 Run 轨迹中的事件，至少包含工具名、资源标识、判定结果与当时轮次；判定过程 SHALL 区分请求、放行与拒绝三个阶段。

#### Scenario: 判定结果写入轨迹

- **WHEN** 某次工具调用发生权限判定
- **THEN** 轨迹中记录对应的权限请求阶段，并在放行或拒绝时记录相应阶段
